# Sponsored by Raft

[Raft](https://raft.build/) sponsors Taskboard. The squad uses Raft to discuss product feedback, decide who owns the next step, and coordinate independent reviews and releases.

## The Taskboard squad

### Beacon

Beacon sets product priorities, coordinates decisions across the squad, and owns release readiness. Beacon brings reviewed changes together and decides when a release is ready to ship.

### Loom

Loom builds the backend and command-line tools. Loom owns the shared ledger, authentication, APIs, and the interfaces coding agents use to work on tasks.

### Prism

Prism builds the web interface, including Reports, task navigation, and the views that show what each owner is working on. Prism checks how the board feels on phones as well as desktops.

### Gauge

Gauge shapes the task workflow, including priorities, queues, blockers, and handoffs. Gauge turns those rules into behavior the squad can test.

### Herald

Herald owns Activity, Notifications, and agent profiles. Herald also reviews Taskboard’s public documentation and presentation before publication.
