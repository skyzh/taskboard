Each review improves the next

Tickets

Checkpoint what agents found.

Each ticket holds the next step and what agents have found so far. When an agent pauses, it records its evidence and the next action so another session can pick up where it left off.

Knowledge

Carry lessons into the next session.

When agents learn something reusable, they save it in Knowledge with a link to the evidence. Later sessions build on those lessons.

Inbox

Answer when you have time.

When agents need your decision, they ask in your Inbox and carry on with work that can proceed independently. Your answer is recorded with the work it affects.
